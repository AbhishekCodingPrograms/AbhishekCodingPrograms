## Featured Engineering Projects

### 1. [VisionMouse — AI Gesture Virtual Mouse](https://github.com/AbhishekCodingPrograms/VisionMouse-AI-Powered-Gesture-Controlled-Virtual-Mouse)
> **Touchless Human-Computer Interface (HCI) translating webcam video streams into high-precision, jitter-free cursor operations.**
- **Tech Stack**: Python, OpenCV, MediaPipe Hands, PyAutoGUI
- **Architecture**: 21-point multi-coordinate landmark pipeline featuring velocity smoothing heuristics and algorithmic coordinate interpolation.
- **Key Capabilities**: Touchless left/right click, drag-and-drop, coordinate tracking, and dynamic window scrolling with sub-30ms latency.

### 2. [AIFit — Biomechanical Posture & Kinematics Analyzer](https://github.com/AbhishekCodingPrograms/AI-Based-Smart-Fitness-and-Preventive-Healthcare-Web-Application-Using-Computer-Vision)
> **Real-time preventive healthcare application evaluating exercise biomechanics and automated repetition tracking.**
- **Tech Stack**: Python, MediaPipe Pose, Scikit-Learn, Flask, React
- **Architecture**: Real-time vector angle calculations across anatomical joint vertices coupled with a machine learning classification model.
- **Key Capabilities**: Automated repetition counting for squats, push-ups, and lunges with sub-degree angular feedback and corrective form guidance.

### 3. [FreightRate Predictor — Shipping Cost Prediction Pipeline](https://github.com/AbhishekCodingPrograms/FreightRate-Predictor-Machine-Learning-Based-Freight-Cost-Prediction)
> **End-to-end multivariate regression pipeline forecasting commercial shipping tariffs based on logistics variables.**
- **Tech Stack**: Python, Scikit-Learn, Pandas, NumPy, Flask
- **Architecture**: Outlier elimination, feature engineering, and cross-validated multi-regressor benchmarking (Linear Regression, Random Forest, Gradient Boosting).
- **Key Capabilities**: High-precision tariff forecasting based on operational cargo weight, transit distance, and carrier metrics.

### 4. [Movie Recommender with Sentiment Intelligence](https://github.com/AbhishekCodingPrograms/Movie-Recommender-with-Sentiment-Intelligence)
> **Hybrid recommendation engine combining metadata content similarity with review sentiment polarity scoring.**
- **Tech Stack**: Python, NLP, TF-IDF Vectorization, NLTK, Scikit-Learn, Flask
- **Architecture**: Dual-filtering engine blending metadata cosine similarity across 5,000+ movies with VADER sentiment scoring on 10,000+ IMDb reviews (88% accuracy).
- **Key Capabilities**: Sub-1.5s query response with explainable similarity metrics and review sentiment distribution.

### 5. [IPL Data Analysis Dashboard](https://github.com/AbhishekCodingPrograms/IPL-Data-Analysis-Dashboard)
> **Comprehensive cricket data analytics engine evaluating 17 seasons of tournament performance.**
- **Tech Stack**: Python, Pandas, NumPy, Matplotlib, Seaborn
- **Architecture**: Aggregated and cleaned datasets covering 1,000+ matches and 800+ players from 2008 to 2025.
- **Key Capabilities**: Interactive performance metrics including strike rate, economy rate, toss influence, and venue-based outcome probabilities.
