## 💼 Executive Summary

I am an **AI & Machine Learning Engineer** and Computer Science undergraduate at **AKGEC**, specializing in **Computer Vision**, **Deep Learning Kinematics**, and **End-to-End Machine Learning Systems**. My engineering focus bridges theoretical deep learning architectures with production-grade, low-latency applications.

- **Computer Vision & Human Kinematics**: Developed touchless human-computer interfaces (*VisionMouse*) and clinical-grade exercise form evaluation models (*AIFit*) leveraging MediaPipe pose topologies and custom geometric angle contracts.
- **Production ML Pipelines**: Experienced in the complete machine learning lifecycle—including data curation, exploratory data analysis, feature engineering, cross-validation, and RESTful API deployment.
- **Algorithmic Problem Solving**: Successfully solved **200+ Data Structures & Algorithms** problems, cultivating strong foundations in computational complexity, memory optimization, and software architecture.
